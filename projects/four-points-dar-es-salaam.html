PROJECT OVERVIEW

Network Infrastructure Upgrade

Supported the network infrastructure upgrade at Four Points by Sheraton Dar es Salaam, working across network rooms and guest/public areas.

The work included structured cabling activities, network rack organization and patching, RUCKUS Wi-Fi access point installation, wireless coverage assessment and infrastructure labelling.

The implementation focused on improving network infrastructure organization, Wi-Fi coverage and operational readiness while following hospitality technology standards.
