PROJECT OVERVIEW

Network rehabilitation in a hospitality environment

The project involved the rehabilitation and restoration of network infrastructure at JW Marriott Masai Mara following infrastructure damage.

Supported hands-on infrastructure rehabilitation activities including structured cabling, network rack restoration, fiber connectivity, network equipment installation, Wi-Fi infrastructure and related ICT systems within the hospitality environment.

MY INVOLVEMENT

Hands-on network rehabilitation

I supported the network infrastructure rehabilitation at JW Marriott Masai Mara through hands-on installation, restoration, structured cabling, fiber connectivity, network equipment deployment and infrastructure testing across the hospitality property.

Network Infrastructure Rehabilitation and restoration of network infrastructure following flood-related infrastructure damage.
Structured Cabling Installation, routing, termination and organization of structured network cabling.
Fiber Connectivity Fiber cabling and connectivity between network infrastructure locations and IDFs.
Wi-Fi Infrastructure Support for wireless infrastructure installation and access point deployment.
Network Equipment Installation, identification, patching and organization of network equipment and rack infrastructure.
Testing & Verification Infrastructure testing and verification to support reliable network operation and project handover.
