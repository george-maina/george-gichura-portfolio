PROJECT 04 • 2024-2026

Marriott Kampala

Hospitality • Kampala, Uganda

Large-scale ICT and ELV infrastructure deployment for Marriott Kampala, covering structured cabling, network infrastructure, fiber connectivity, Wi-Fi, IPTV, telephony and CCTV from installation through testing and commissioning.

PROJECT OVERVIEW

End-to-end hospitality technology deployment

Supported the deployment of the hotel's ICT and ELV infrastructure from construction-stage installation through system testing and commissioning. The scope covered structured cabling, network infrastructure, fiber connectivity, Wi-Fi, IPTV, telephony and CCTV systems.

The project involved extensive field installation, network rack and IDF preparation, cable routing and management, equipment installation, identification, patching, testing and commissioning across the hospitality property.

MY INVOLVEMENT

From infrastructure installation to system commissioning

I supported the Marriott Kampala project through hands-on ICT and ELV infrastructure deployment, working across structured cabling, network infrastructure, fiber connectivity, network racks, Wi-Fi, IPTV, telephony and CCTV systems. My involvement extended from physical infrastructure installation and termination through equipment deployment, testing and final commissioning activities.

Structured Cabling

Installation, routing, termination, dressing, labelling and organization of structured network cabling across the property.

Network Infrastructure

Network rack installation, IDF infrastructure, patching, equipment identification, cable management and network infrastructure preparation.

Fiber Connectivity

Fiber infrastructure installation, termination and connectivity between network infrastructure locations and IDFs.

Wi-Fi Deployment

RUCKUS access point installation, cabling, identification, deployment support and wireless infrastructure testing.

IPTV Systems

Supported IPTV infrastructure installation, guest-room connectivity, equipment deployment, testing and commissioning.

Telephony

Supported hotel telephony infrastructure, structured cabling, connectivity, equipment installation and system testing.

CCTV Systems

Supported CCTV infrastructure cabling, device connectivity, equipment installation and testing as part of the hotel's integrated security systems.

Testing & Commissioning

Infrastructure testing, fault identification, verification, system testing and commissioning support prior to operational handover.
